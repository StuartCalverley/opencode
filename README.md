# OpenCode

An open-source repository providing **agents** and **skills** to help create and manage structured projects with high user involvement.

## Overview

OpenCode empowers users to build well-organized projects through intelligent agents and modular skills that streamline project management and structure. With a focus on user engagement and control, OpenCode makes it easy to implement best practices and maintain consistency across your projects.

## Features

- **Intelligent Agents**: Automated workflows to manage project tasks and processes
- **Modular Skills**: Reusable components for common project operations
- **User-Centric Design**: High user involvement in project decision-making and customization
- **Structured Approach**: Maintain consistency and organization across your projects
